# Безопасная смена — мини-игра

**[Играть в браузере](https://kidisildur1.github.io/fire-safety-quest/)**

Двухмерная мини-игра с видом сверху для сотрудников лабораторий и офисов научного кластера. Игрок управляет сотрудником, исследует помещения и действует при учебной тревоге.

## Как играть

- **WASD / стрелки** — движение; **E / пробел** — действие рядом с объектом.
- Можно нажать на свободное место карты или задачу в журнале: персонаж сам обойдёт стены и мебель.
- На телефоне доступны кнопки направления и взаимодействия.
- Звук включается по желанию. Прогресс сохраняется только в текущем браузере.

## Два игровых эпизода

1. **Обход до начала работы.** Найти повреждённый кабель и огнетушитель с сорванной пломбой, передать отметки ответственным, перенести лёгкие пустые коробки из прохода в зону хранения. Коробки можно перетаскивать или переносить нажатием.
2. **Учебная тревога.** Предупредить людей извещателем или голосом, набрать 101 / 112 на учебном телефоне, передать известные сведения и выйти по свободному пути к месту сбора. Выход доступен сразу: вызов разрешается завершить снаружи.

Дым и обычный лифт не являются игровыми сокращениями маршрута. Персонаж останавливается перед опасным выбором, а игра объясняет причину. Таймера, награды за скорость и необходимости закончить задания перед эвакуацией нет.

Итог показывает отработанные действия и разобранные опасные решения. Повторить сценарий можно кнопкой «Новая смена».

## Учебные ограничения

Карта, адрес, имена и место сбора условные. Телефон не совершает реальных звонков. Отметки о неисправностях не отправляются в какие-либо системы.

Материал опирается на четыре предоставленные инструкции по пожарной безопасности; ссылки на их номера и пункты включены в разбор игры. Исходные внутренние документы в репозитории не публикуются. Перед применением в организации сценарий следует сверить с действующими локальными инструкциями и реальными условиями объекта. Игра не заменяет инструктаж, практическую отработку и проверку знаний; её результат не является допуском к работе.

## Запуск и устройство

Сайт работает без сборки, регистрации, внешних библиотек и серверной базы данных. Для локального просмотра запустите из этой папки `python -m http.server 8000`, затем откройте `http://localhost:8000`.

- `index.html` — интерфейс игры.
- `game.js` — движение, поиск пути, взаимодействия, учебный телефон и сохранение.
- `game-art.js` — карта и персонаж, отрисовка Canvas 2D.
- `game.css` — адаптивное оформление.
- `assets/favicon.svg` — значок сайта.

GitHub Pages публикует корень ветки `main`. Никакой аналитики, регистрации или передачи результатов нет.
