# Безопасная смена

Интерактивный учебный квест по пожарной безопасности для сотрудников лабораторий и офисов научного кластера.

**[Открыть квест и попробовать](https://kidisildur1.github.io/fire-safety-quest/)**

## Что можно попробовать

- Найти риски на интерактивной схеме лаборатории.
- Проверить готовность огнетушителя.
- Выбрать информативное сообщение о пожаре.
- Принять решение о безопасной эвакуации.
- Завершить рабочий день и проверить электроприборы.

После каждого решения появляется объяснение. Итог показывает освоенные навыки и число миссий, пройденных с первой попытки. Прогресс сохраняется только в браузере пользователя; его можно сбросить кнопкой «Начать заново».

Это демонстрационная учебная версия. Она не заменяет инструктаж, практическую отработку или проверку знаний по установленной процедуре. Ситуации и адрес в упражнении условные. Перед применением в организации содержание нужно сверить с действующими локальными инструкциями и реальными условиями объекта.

## Запуск

Сайт работает без сборки, регистрации и серверной базы данных. Для локального просмотра запустите статический сервер из этой папки, например `python -m http.server 8000`, и откройте `http://localhost:8000`.

Для GitHub Pages выберите публикацию из корня ветки `main` в настройках репозитория: **Settings → Pages → Deploy from a branch**.

## Состав

- `index.html` — оболочка приложения.
- `styles.css` — адаптивный интерфейс.
- `app.js` — пять миссий, обратная связь и сохранение прогресса.
- `assets/` — иллюстрация и значок сайта.

Исходные внутренние документы, персональные данные, ключи доступа и аналитика в состав публикации не входят.
